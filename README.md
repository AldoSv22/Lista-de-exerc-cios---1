# Tecnologias e Ferramentas Utilizadas

## Tecnologias

- **JavaScript**: Linguagem de programação utilizada no desenvolvimento.
- **Node.js**: Ambiente de execução para rodar código JavaScript fora do navegador.

## Ferramentas

- **prompt-sync**: Biblioteca utilizada para permitir entrada de dados via terminal (input do usuário).

## Como acessar e executar

1. **Instalar o Node.js**  
   Baixar e instalar a versão mais recente do Node.js pelo site oficial:  
   👉 [https://nodejs.org](https://nodejs.org)

2. **Instalar dependência**  
   Abrir o terminal no diretório do arquivo e executar:
   ```bash
   npm install prompt-sync
